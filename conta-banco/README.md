# 💰 ContaBanco - Desafio DIO 🚀

Este projeto foi desenvolvido como parte da trilha de Java Básico da DIO, com o objetivo de praticar conceitos fundamentais da linguagem, como entrada de dados, variáveis, concatenação de strings e uso da classe `Scanner`.

## 📋 Descrição do Desafio

O programa solicita ao usuário as seguintes informações via terminal:

- Número da Agência (ex: `067-8`)
- Número da Conta (ex: `1021`)
- Nome do Cliente (ex: `MARIO ANDRADE`)
- Saldo Inicial (ex: `237.48`)

Após inserir os dados, o sistema exibe uma mensagem formatada confirmando a criação da conta.

## 🛠️ Tecnologias Utilizadas

- Java
- Scanner para entrada de dados
- Concatenção de strings
